## 机房位置为什么排在配置前面

有个做独立站的人记录过自己的踩坑：最早用国内某云的香港节点跑外贸站，自己打开飞快，海外客户那边延迟 250ms 起步，Google PageSpeed 评分常年在 60 分。换成美国西海岸机房后，海外评分直接到 85。

同一个网站、同一套代码、同一份图片，只是机房换了地方。

原因是外贸站要同时照顾两类人：掏钱的买家在欧美，改内容的人在国内外。服务器放在买家那边，爬虫抓取和首屏渲染都快；放得离买家远，浏览器要跨洋握手好几次，页面再优化也白搭。

所以规则很直白：买家在美国、欧洲，机器放美国西岸；买家在东南亚，再看香港、新加坡、台湾。你自己的后台会不会卡，是第二位的事，加钱换线路档就能缓解。

## 日 PV 不到一千，2G 内存就是浪费

低价 VPS 最常见的问题是超售：标称 4 核 8G，高峰期 CPU 和内存被同机的其他用户抢走，你的站打开转圈。挑机器的时候，"资源是不是独占"比"数字有多大"重要。

内存该配多少，按访问量算比较靠谱：

- 日均一两千 PV 的 WordPress 站，2G 内存加双核够用，再往上加感觉不到
- 1G 内存跑 WordPress 加 WooCommerce，要把内存压在 600MB 以内，重型插件全得禁掉
- 一台机器挂多个站：4G 跑 2 到 3 个轻量站，6G 跑 3 到 5 个，8G 以上才谈得上 5 个以上

日 PV 还不到 1000 的新站，直接买 2G 以上的配置，多出来的内存一年也用不上几次。先上 1G，等 Google Analytics 里的数字真的压不住了再升。

硬盘倒是不能省。HDD 是 IO 瓶颈，WordPress 读图片、读缓存、查数据库全在这上面卡着，电商类站点尤其明显。LightLayer 洛杉矶全线给的是 NVMe，这一点在同价位里算是到位。

## 原生 IP 到底管不管 SEO

不少人买美国 VPS 是冲着"原生 IP 对 Google 排名有帮助"这句话去的。这句话得拆开看。

Google 排名看的是内容质量和 Core Web Vitals 这类页面性能指标，IP 是不是原生，不直接进入排名计算。一个内容稀烂、打开要五秒的站，换成原生 IP 也上不去。

原生 IP 真正值钱的地方在平台风控。做独立站要接 Stripe 收款、要投 Facebook 广告，这些平台会判断你的登录环境和服务器 IP 是否干净。机房 IP、被大量共用的 IP，触发二次验证、限制账户、拒审广告的概率明显更高。原生 IP 加上干净的风险评分，账户能活得久一些。

LightLayer 洛杉矶是原生 IP，有测评记录显示其 IP 质量检测判为家宽倾向、黑名单干净、Netflix 与 ChatGPT 均识别为美国原生。台湾、香港、新加坡三个机房是广播 IP，注册地和实际使用地对不上，平台识别时可能判成非本地。

要接支付、要投广告的外贸站，洛杉矶原生 IP 这一条就够定下来了。

## 几个买之前会卡住的问题

**1G 内存能跑 WordPress 加 WooCommerce 吗？**

能，但只能跑一个干净的站。把内存控制在 600MB 以内，插件精简到必需的那几个，缓存和图片压缩都开起来。产品页超过 200 个、或者装了多语言插件，直接上 2G 起步。

**买家在欧美，机房选洛杉矶还是香港？**

选洛杉矶。香港的价值是到国内延迟低，对欧美的物理距离摆在那里，跨太平洋绕一圈反而不划算。买家在东南亚、或者你自己天天要登后台，香港、新加坡才有意义。

**不限流量和 1T/月 该选哪个？**

看端口。不限流量的档位端口小（20M 到 50M），限额 1T 的档位端口大（30M 到 200M）。图片多、单页体积大的站选大端口，因为瓶颈在带宽不在流量；纯文字站、访问量稳定但单页轻的，不限量更省心。官网两种计费方式都提供，下单时看清楚标的是哪一种。

**能不能装 WordPress、WooCommerce、OpenCart？**

可以。KVM 虚拟，标准 Linux 系统随便装，宝塔、LNMP 一键包都能跑。

**服务器能发邮件吗？**

有测评提到该机房 25 端口出站被阻断。外贸站的订单通知、询盘提醒别指望服务器直发，接第三方 SMTP 服务或者用邮件 API，这个在部署时就要规划好，不然后面排查很浪费时间。

**怎么付款？**

支持加密货币、信用卡、PayPal、支付宝。有其他付款方式的需求，得联系官方。另外每个产品每个客户限购 2 台，下单后 1 小时内没付款订单会被取消。
